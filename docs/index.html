What's Inside

⚡

Zero-Config Auto Forge

Single function chains: propose → test → verify → secure. Auto-detects JS vs text skills, generates test scenarios, security scoring.

📱

Phone-Aware Auto-Creation

Real OS telemetry: battery, network, screen, geolocation. Gap detection suggests skills based on your usage patterns.

🧠

Self-Evolving Skills

Usage analytics, feedback collection, auto-refine. Skills improve based on real usage data.

📦

Edge Gallery Export

Export to SKILL.md format with kebab-case naming. Configure run_js or run_intent tools.

🔒

Security Built In

Leak/smell detection, security scoring, secrets handling for API keys and tokens.

🔌

Native Android Plugins

Geolocation, network, filesystem, clipboard, status-bar. Full native capability via Capacitor.

How to Install

Three ways to get Skill Lab on your device

1

Download APK

Get the latest APK from GitHub Releases

2

Enable Install from Unknown Sources

Settings → Security → Unknown Sources → Allow (or during install if prompted)

3

Install & Open

Tap the APK file → Install → Open. That's it!

+

Build from Source (Developer)

git clone → npm install → npm run android:build
